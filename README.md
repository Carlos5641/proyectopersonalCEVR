# Portal personal profesional de identidad

<p align="center">
  <img src="varios/logos.png" width="300">
</p>

Plantilla desarrollada en HTML5, CSS3 y JS.

---

### Descripción del proyecto:
Sitio web personal desarrollado para presentar perfil profesional, currículum vitae, portafolio de proyectos y datos de contacto de manera responsiva y organizada.

### Tecnologías utilizadas:
- ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) **HTML5**: Maquetación semántica del sitio.
- ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white) **CSS3**: Estilos, diseño responsivo y presentación visual.
- ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black) **JavaScript**: Interactividad y dinamismo del portal.
- ![Git](https://img.shields.io/badge/Git-F05032?style=flat&logo=git&logoColor=white) **Git & GitHub**: Control de versiones y repositorio remoto.

---

### Archivos principales:

- `index.html` - Página de inicio del portal.
- `identidad.html` - Filosofía, visión y valores.
- `portafolio.html` - Trabajos y proyectos realizados.
- `cvu.html` - Currículum vitae y trayectoria académica.
- `acerca.html` - Semblanza personal e intereses.

### Estructura de la plantilla:

```text
/--
|-- css   .- Hojas de estilo para las páginas html
|-- img   .- Imágenes utilizadas en las páginas html
|-- varios.- Archivos para el diseño de readme.
```
